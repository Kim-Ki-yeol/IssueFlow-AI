HOW IT WORKS

이슈 등록부터 알림까지,
다섯 단계로 이어집니다.

GitHub Actions에서 Python 프로그램을 실행하고, 분석 결과를 다시 이슈에 반영합니다.

01

새 이슈 등록

GitHub Issues에 버그, 기능 요청 등이 등록됩니다.

GitHub Issues
02

워크플로우 실행

등록 이벤트를 받아 Python 프로그램을 실행합니다.

GitHub Actions
03

이슈 분석

유형, 우선순위, 확인할 항목을 정리합니다.

OpenAI GPT / LangChain
04

GitHub 반영

허용된 라벨을 붙이고 분석 댓글을 작성합니다.

GitHub REST API
05

알림 전송

원하는 경우 분석 결과를 Discord로 보냅니다.

Discord Webhook

서비스 연결 상태

01
환경변수 설정

02
연동 확인

03
